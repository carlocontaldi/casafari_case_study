# Casafari Case Study
Data science case study on real estate data extraction, querying and analysis based on real-world Casafari data. All my work has been carried out in the provided Jupyter Notebook (`notebook.ipynb`), which also includes an in-depth description of my thought process. This project has been carried out in 4 days (time allotted for the challenge).

# Highlights
- Data Extraction: crawled relevant information from website using CSS3/XPath selectors and regex.
- Data Querying: implemented fully working MySQL platform and executed complex queries.
- Data Preparation: cleaned and feature-engineered property entries using regex filtering/mapping and TF-IDF vectorizers.
- Data Analysis: identified investment opportunities with an outlier detection solution based on DBSCAN.
